# Exercise figures

The SVG frames in this directory come from [Workout Guide](https://github.com/bryllim/workout-guide)
by Bryl Lim, which builds on pose artwork from [Everkinetic](https://github.com/everkinetic/data).
Both are licensed under [CC BY-SA 4.0](https://creativecommons.org/licenses/by-sa/4.0/).

Changes made here: files renamed to this app's exercise ids (`goblet-1.svg` = `goblet-squat/frame-1.svg`,
`arms-1..3` = `bicep-curl`, `arms-4..6` = `dumbbell-overhead-tricep-extension`, `walk` = `treadmill-incline-walk`,
`press` = `seated-dumbbell-press`, `rdl` = `dumbbell-romanian-deadlift`, `row` = `seated-row`,
`bss` = `bulgarian-split-squat`, `deadbug` = `dead-bug`, `facepull` = `face-pull`, `pulldown` = `lat-pulldown`,
`stepup` = `step-up`, `bench` = `dumbbell-bench-press`). The frames are displayed as CSS masks and tinted with the
app's ink colour; the files themselves are unmodified. These adaptations are shared under the same CC BY-SA 4.0 license.
